# 🧠 Focus – Gamified Productivity & Wellness Tracker (iOS)

**Focus** is an iOS-only app that helps users build better habits by combining productivity tools with wellness tracking — all driven by a gamified point system and social accountability. Whether you're aiming to stay on top of tasks or improve your daily activity, Focus keeps you motivated and consistent.

Built in Swift/Xcode, Focus was founded and led end-to-end, from initial concept through a 100+ user TestFlight beta, by a team of 3 engineers.

---

## 📱 Key Features

- ✅ **To-Do List & Daily Planner**
  Organize your day with a built-in to-do list designed for speed and clarity.
- 📓 **Journaling**
  Reflect on your progress or log your thoughts with the integrated daily journal.
- 💪 **Apple Health Integration**
  Automatically sync step count, active minutes, and workouts to earn points, eliminating manual input as the core user pain point.
- 🏅 **Point System & Leveling**
  Earn points for completed tasks and physical activity — turn good habits into measurable progress. The scoring system was modeled and tuned with a custom Python simulation script prior to launch.
- 🌍 **Social Leaderboards**
  Join public and friends-only leaderboards to stay motivated through friendly competition, with friend requests and Google/Apple ID authentication built on Firebase.
- 📊 **Progress Tracking**
  Visual dashboards to help you monitor productivity and wellness trends over time.

---

## 🏗️ Under the Hood

- **Frontend**: Swift, Xcode, Apple HealthKit
- **Backend**: Firebase (NoSQL) for the social layer, authentication, and data sync
- **Growth engine**: Firebase Cloud Functions (JavaScript) powering targeted push notifications
- **Modeling**: Python simulation script used to design and balance the points system before launch
